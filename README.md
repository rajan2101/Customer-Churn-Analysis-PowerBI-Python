## 🎯 Project Objective
The goal of this project was to analyze customer data to identify the key drivers of churn and provide actionable recommendations to increase retention.

## 🛠️ Tech Stack
- **Python (Pandas, Seaborn):** Used for Data Cleaning and Statistical Correlation.
- **Power BI:** Created an interactive dashboard for Executive reporting.
- **Excel:** Initial data audit and cleaning.

## 💡 Key Insights
- **Tenure:** Strong negative correlation (-0.35). New customers are at the highest risk.
- **Contract Type:** Month-to-month users churn at a 42% higher rate than yearly users.
- **Service Type:** Fiber Optic users show higher dissatisfaction compared to DSL.

## 🚀 Recommendations
1. Launch a loyalty program for customers in their first 6 months.
2. Offer incentives for Month-to-Month users to switch to 1-year contracts.
